# Shared FDTD utilities

Material models, dispersion updates, and broadband utilities used by the solvers.
The shared Ez/Hz compiled runtime, CUDA stepping, and cut-cell helpers also live
here. The 3D CUDA runtime lives in `FDTD_3D/cuda.py`.
