# Earlier Cartesian UPML TMz solver

This is the oldest retained Ez implementation, using UPML.
The later CPML implementation lives at `FDTD_2D_Ez`.
The supported CPML solvers are `FDTD_2D_Ez` and `FDTD_2D_Hz`.
The general geometry-first solver lives on the separate `dev` branch.
