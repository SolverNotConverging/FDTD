# Historical solvers

`FDTD_2D_Ez_UPML` preserves the earlier UPML implementation:

```python
from legacy.FDTD_2D_Ez_UPML import FDTD_2D_Ez
```

The supported CPML implementations live at the repository root as
`FDTD_2D_Ez` and `FDTD_2D_Hz`. The general geometry-first solver and its GUI
are maintained on the `dev` branch.
