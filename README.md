# FDTD
A baby level FDTD solver that can perform 1D and 2D simulations. CPML is used. 
It supports anisotropic materials, SF/TF sources, waveguide eigenmode sources, 
fft of source and flux power, NF2FF. It can run on a GPU (PyTorch required).

3D version is under development.
